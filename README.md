# RGB Agent Hacker Kit

Builder kit for the QVAC × RGB hackathon: links, install commands, tested local models and wallets for building AI agents that hold and move RGB assets with KaleidoSwap tooling.

Live at https://kaleidoswap.github.io/rgb-hackathon/. It is a single static `index.html` served by GitHub Pages; edit it and push to `main` to update the site.
